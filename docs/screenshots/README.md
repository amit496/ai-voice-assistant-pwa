Screenshots to capture for portfolio/demo

Place screenshots in this folder with the following filenames:

1. `screenshot_home.png` — App homepage with microphone UI
2. `screenshot_agent_connected.png` — Agent connected status (showing live transcript or bars)
3. `screenshot_voice_response.png` — When audio response plays (show console log)
4. `screenshot_console_logs.png` — Full console showing key logs (agent session, voice, chat)
5. `screenshot_deploy.png` — Vercel deployment overview (optional)

How to capture:
- Use macOS Shift+Cmd+4 to capture selected area
- Keep images under 2MB

Add images to `docs/screenshots/` and commit with documentation.
